# Recorded prefix qualification

This changes qualification only. With no `STRATA_SUFFIX_REPAIR_QUALIFY=1`, serving retains the original prefix decisions and does not allocate a replay transcript, invoke a replay callback or issue extra numerical work. Wholly T1 prefixes, including the existing boundary36 profile, retain the existing T1 oracle and allocate no transcript vectors. The current released small-profile artifact does not contain this slice.

For actual batched prefixes, qualification requires an actual reset/from0 read, fixed prefill16/short64, owned native serial stages, explicit `STRATA_PREFILL_CPU_SHARE=0`, disabled helper/peer/observer writers and a stable source/cache mapping. Existing ordinary exact-prefix checkpoint reuse retains priority; checkpoint/slot/parked ancestry is unsupported by this adapter. Unsupported schedules refuse suffix installation after checked completion of the original exact prefix; they cannot silently use an allT1 oracle. Production prefix selection/checkpoint policy and the unflagged524288 default do not change.

The existing qualification H/global admission additionally prices typed event capacity, one complete residency vector, one canonical exact loan directory per stage, a bounded int64 token view and callback metadata. Its original credit owner outlives all transcript storage. Vectors allocate lazily before the first actual batched loan. Recording covers actual window intervals and the real read_part `run(q,r)` calls/force flags; it does not infer a plan from DONE. Original loan/refill uploads propagate their original status with checked owning-device scopes. Different subsequent loan shapes refuse installation.

After private retirement, checked refill must reproduce the entire base mapping and stable cache/source/layout identities. The clean oracle genuinely resets native state, executes the sealed numerical prefix through borrowed callbacks to the same live Prefill objects, then teacher-forces actual accepted history through the existing T1 driver. It suppresses serving checkpoint/progress callbacks, samples/emits no replacement tokens, and does not seed from the saved edited prefix. Strict all-stage native, padding, history/watermark, pending continuation and final repaired restoration remain mandatory. The existing first-output distribution diagnostic is read at its actual later conditioning position.

`SuffixExperimentDriver::replay_prefill_piece` owns RAW authority. Actual callback success alone is insufficient: original runtime/stage/verifier/allocation identities must remain unchanged, public Prefill joins and every actual owned device must finish, actual stage endpoints and PLE epilogue must agree, and verifier drains/dispatch must remain healthy before a common cut is completed. Uncertain errors take the existing noreturn path with original owners retained; no rollback after partial writes is claimed.

STOP remains latched. Qualification temporarily moves the original callbacks, disables per-stage should_stop and uses primary stop_at_chunk to stop only between issued chunks. Unlike should_stop's immediate return, that existing break executes the PLE epilogue. Downstream tasks receive only already issued rows and are joined. A verified partial common endpoint permits checked refill and restoration of the saved final repaired image, then reports cancelled qualification. A missing endpoint/PLE/drain or failed downstream join failstops before a certificate/restore. No production STOP wait or new sampling path is added.

An actual batched oracle emits:

```
suffix_repair_prefix_replay req=2 boundary=... reached=... schedule=<64hex> events=... batches=... windows=... ancestry=reset_from0 mapping_equal=1 completed=1 stages=2 policy=fixed_prefill16_short64 elapsed_ms=... binary=<64hex> source=<64hex>
```

A successful calibration requires exactly one target record, reached=boundary, batches>=1, events=batches+windows, expected actual stages/identities and finite elapsed time. The schedule digest attests the sealed production calls/loans/map; it is not an independent numerical proof. completed0 cannot award qualification PASS. Final native/pending oracle records remain separately required. No long-state applicability or performance claim follows from this receipt alone.

`test_prefix_replay.py --build-dir <scratch>` compiles/executes extracted actual policy/prepare/loan/base/callback/refill/upload/RAW-bridge code and actual Prefill public join/STOP/PLE branches at recording CPU seams. It covers a real child address-space allocation refusal before any loan while holding the admitted owner, unsupported/checkpoint ancestry, changed canonical loan/full mapping, original secondary upload error without retry, callback suppression/restoration with STOP latched, common endpoint/PLE on graceful break, failed downstream join/exception/device drain retaining owner sentinels, valid participant/allocation substitution refusal, missing batched plan, stale cut and completion refusal. The original should_stop branch is a negative control demonstrating skipped PLE epilogue. CUDA/cache/row stubs prove control and lifetime behavior only; they do not prove physical drains, native bytes, allocation fit or GPU cancellation. Actual later-prefix calibration at occupied1k/4k with boundary>64 and real loans remains required before larger occupied cells.

The existing first-output fixture extracts the actual T1-tail loop with prefix_at=0 to preserve its old-path/readback checks. Cancellation bookkeeping/fault fixtures retain their source behaviors. No CPU tests or native execution are claimed until their owner records actual gate results.
